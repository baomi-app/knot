# Knot 隐私政策

更新日期：2026年9月16日

[English](privacy-policy.md)

Knot 的核心功能在 Mac 本地运行，无需账号，不包含广告或分析服务，也不运营个人数据收集服务。更新检查和你主动打开网站时会涉及网络访问，具体说明如下。

## 在 Mac 本地处理的数据

- 用于搜索结果的应用名称和本地文件元数据。
- Knot 运行期间用于剪贴板历史的文字和图片。
- 你主动执行截图或 OCR 命令时的屏幕内容。
- 窗口管理命令所需的窗口信息。
- Quicklinks、快捷键、偏好设置、使用排序和截图记录元数据。

剪贴板历史使用 AES-GCM 加密，密钥保存在 macOS 钥匙串。OCR 使用 Apple 的设备端 Vision 框架。Knot 不会将剪贴板历史、截图或文件作为遥测数据上传。本地应用/文件搜索和 OCR 不会将输入发送至服务器；但搜索类 Quicklink 会将你主动提交的查询发送到目标网站。

## 剪贴板过滤与保留规则

默认条数为 100 条，对未置顶内容应用 30 天保留期。置顶内容不受保留期限制，也可能超过设置的条数，但加密归档仍受 128 MiB 文件大小预算限制。可在设置中调整条数、保留期及排除应用。过期清理在应用历史策略时执行，例如启动、捕获内容或设置变化时；闲置期间不会在到期的准确时刻定时删除。

Knot 跳过标记为 concealed、transient 或 auto-generated 的剪贴板内容，并默认排除若干密码管理器。这些是**尽力而为的保护，不保证绝不记录密码或其他秘密**。并非所有应用都会标记敏感内容，且来源应用根据轮询剪贴板时的前台应用推断。快速切换应用可能造成归因错误；来源未知时也不会自动排除。加密保护的是落盘归档，不是应用中显示的内容或重新写入系统剪贴板的内容。

## 系统权限

- **辅助功能**：移动、调整窗口，以及将选中的历史内容直接粘贴到其他应用。
- **屏幕录制**：你主动发起的截图及 OCR。
- **登录时启动**：可选，仅在你主动开启后启用。

辅助功能和屏幕录制权限可在“系统设置 → 隐私与安全性”中管理；登录项可在“系统设置 → 通用 → 登录项”中管理。这些权限并不代表授权上传屏幕或剪贴板内容。

## 存储与删除

Knot 未启用 App Sandbox，数据并不保存在应用容器中。

| 数据 | 位置或行为 |
| --- | --- |
| 加密剪贴板归档 | `~/Library/Application Support/Knot/clipboard-history.bin` |
| 加密恢复副本 | 同目录下的 `clipboard-history-recovery-*.bin` |
| Quicklinks、其恢复副本、截图索引 | `~/Library/Application Support/Knot/` 中的其他文件，不由 Knot 加密 |
| 偏好设置及使用排序 | UserDefaults 域 `app.baomi.knot` |
| 保存的截图 | Capture 设置中选择的目录；开启保存时默认目录为 `~/Pictures/Knot Captures`；文件不由 Knot 加密 |
| 剪贴板加密密钥 | 钥匙串 service 为 `app.baomi.knot.clipboard.v2`，account 为 `history-key` |

**Clear Clipboard History 会删除当前归档，但有意保留已有恢复副本。** 恢复副本用于在替换不可读数据前保护原始数据，没有自动过期清理。**Clear Capture History 只删除索引，不删除截图文件。** 这两种操作都不意味着安全擦除磁盘块或外部备份；清空历史也不会清空当前系统剪贴板。

如需删除其余本地数据：

1. 退出 Knot，避免删除时重新生成文件。
2. 在 Finder 中使用“前往 → 前往文件夹”打开 `~/Library/Application Support/Knot`。删除剪贴板归档和恢复副本可移除存储的剪贴板历史；删除整个目录还会移除 Quicklinks 和截图索引。
3. 单独删除配置的截图目录内的截图，以及导出至其他位置的副本。
4. 如需重置所有偏好设置和使用排序，在 Knot 关闭时于终端执行 `defaults delete app.baomi.knot`。此操作只删除设置，不删除截图或钥匙串项目。
5. 如需彻底卸载，可在“钥匙串访问”中删除对应的 Knot 剪贴板密钥。早期开发版本可能还留有 `app.baomi.knot.clipboard` 旧项目。删除密钥后，用它加密的归档将无法读取；如果仍需恢复归档，请勿删除相应密钥。
6. 按需清空废纸篓。备份、同步目录及当前系统剪贴板需单独管理。仅删除 Knot.app 不会删除其用户数据。

## 网络访问

**默认开启自动更新检查。** Sparkle 检查 GitHub Releases，并通过 GitHub 及其下载 CDN 下载更新。服务器会接收 IP 地址、HTTP 请求头等常规连接信息。自动下载默认关闭。可在 Settings → General 中修改检查和下载设置。关闭自动检查后，手动检查或下载更新仍会访问网络。

Sparkle 系统信息分析功能已禁用。更新请求不包含剪贴板内容、截图、文件或搜索词。

Quicklinks 会交由对应程序（通常为浏览器）打开所选网址；搜索类 Quicklink 包含你主动提交的查询。帮助和隐私政策等外部链接也会访问目标网站。对方根据各自的隐私政策处理这些请求。

## 政策变更与联系方式

政策变化时，将在 baomi.app 与 Knot 仓库发布更新内容和日期。如有隐私问题，请通过 [baomi.app](https://baomi.app) 的联系方式联系我们。
